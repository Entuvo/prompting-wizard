# claude-long-context

For document inputs above roughly 20,000 tokens, place documents before the query. Distinguish documents and sources clearly. Ground analysis in relevant passages. Verify benefits on your own task.

Source: [claude-long-context](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices#long-context-prompting). Checked 2026-10-08. Revision 2026-10-08.1.

The manifest deliberately lists exact reviewed model IDs. This is not a prefix rule for future models. Unknown identity uses core course principles. Sources older than 90 days are flagged for review; stored history is never rewritten.
