# Day 21 — Context ordering: task, material, constraints

## Concept

Three hundred words of context before the instruction means the model reads the whole block without knowing what it's for, then has to look back to work out which parts mattered.

Reordering the same content — task first, material second, constraints grouped last — changes nothing about what's included, only when it's read. Task first gives every sentence that follows something to be filtered against. Material second supplies what needs filtering. Constraints grouped last land right before the model starts writing, instead of getting skimmed a paragraph ago and forgotten by the end.

This is a pure reorder, not a trim. The test is whether you deleted anything to make the new version read better — if you did, the old order wasn't hiding structure, it was hiding padding you should have cut anyway.

Here is the test: is the instruction the first thing read, and where does each constraint sit? Constraints scattered through the material is where this starts; all but one grouped at the end is the climb from there; every one grouped last is the top. Predicting what the reordered version changes about the output is a useful habit, not a scored one.

The two constraints, grouped at the end instead of buried mid-paragraph, are the last thing read before the model starts writing.

## Exercise

Before presenting a tier, read `## Levers` from the learner's `PROGRESS.md`, identify the three lowest-scoring levers, and name them to the learner. Ask the learner to choose a real task from `## Tasks`. Then the tutor writes and shows one 200+ word source prompt for that task, with its instruction buried at the end and at least three constraints scattered through the material. Thread the three weak levers through that source as imperfections — for example, if pronoun is weak, include an unresolved "it"; if numeral is weak, bury a quantity in prose instead of stating it as a number; if conjunction is weak, hide an unstated fallback inside a sentence. The source prompt is exercise material, not the learner's answer; every tier below asks the learner to reorder that same source without adding, deleting, or rewriting words. Naming the weak levers is a useful habit, not a scored one — today's score is `context-ordering` alone, so the weak levers are exercised, not repaired.

### Novice

Point out where the instruction sits in the source prompt. Ask the learner to move it to the top while leaving every constraint exactly where it falls, without adding, deleting, or rewriting a word, and send that reordered version as their prompt.

### Working

Ask the learner to move the instruction to the top and group the source prompt's constraints at the end, leaving exactly one constraint where it currently sits mid-material, without adding, deleting, or rewriting a word, and send that version as their prompt.

### Advanced

Ask the learner to reorder the source prompt into task first, material second, and every constraint grouped last with none left early, without adding, deleting, or rewriting a word, and send that version as their prompt.
