# Day 6 — Composition: the first five together

## Concept

You've practised noun, verb, adjective, adverb, and preposition one at a time. Nothing today is new. Today is about running them together, because each lever constrains a different dimension of the same request, and setting one does not substitute for setting the others.

The noun says what lands. The verb says what operation produces it. The adjective says what would make you reject it. The adverb says how thoroughly. The preposition says where it stops, who it's for, and what it must not touch. Naming the artifact tells the model nothing about depth; setting depth tells it nothing about audience. A sharp noun alone is exactly as underspecified on manner as no noun at all — just underspecified on a different axis.

A composed prompt is not five sentences bolted together. It's one sentence carrying five jobs, each done by one word or phrase, none fighting for the same space. That's what makes it short and still complete.

Here is the test: remove each lever in turn. If the sentence still reads as a full instruction with one gap, that lever wasn't pulling weight. If it collapses into ambiguity, it was.

## Before / After

**Before**

> Look at {{TASK}}.

**After**

> Rank the correctness issues in {{TASK}} into a blunt, jargon-free list, one bullet per issue with none omitted, for a reader new to the codebase, without proposing API changes.

Every word above is doing exactly one lever's job: "rank" is the verb, "list" the noun — the ranked list is the artifact the prompt asks for — "blunt, jargon-free" the adjectives, now constraining that list rather than the issues it ranks, "one bullet per issue with none omitted" the adverb, "for a reader new to the codebase, without proposing API changes" the preposition — audience and exclusion, not audience alone. The correctness issues in {{TASK}} are the input being ranked, not the artifact itself; nothing is left for the model to invent.
