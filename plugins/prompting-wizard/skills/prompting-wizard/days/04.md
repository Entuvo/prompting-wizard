# Day 4 — Adverb: manner and degree

## Concept

"Review {{TASK}}" names the operation but not how hard to push it. "Review briefly" is barely better — briefly compared to what? Two readers given "briefly" will produce a one-line note and a half-page write-up, both honestly briefly, and disagree about which one was right.

Adverbs set manner and degree: how thoroughly, how carefully, in what style. Without a measure attached, a manner word is a mood, not an instruction. "Carefully" tells the model to feel careful. "Claim by claim, checking each against the supplied source" tells it what careful output looks like.

Depth doesn't have to be uniform across a task. You can set one part deep and another shallow, each with its own measure — that's still one lever, applied twice with two different settings, not two levers.

Here is the test: if two competent people followed this manner word, would their outputs be the same length and thoroughness? Measuring the one part where depth matters most and leaving the rest to guess is a rung of its own; a measure across the whole task is the climb from there, and one on every part is the top.

## Before / After

This fixed example illustrates the technique; apply it to your own task in the exercise.

**Before**

> Review the research summary.

**After**

> Review the research summary claim by claim against the supplied source: one line per claim, marked supported, contradicted, or not verifiable from that source. Then review style in three sentences: one each on clarity, tone, and repetition; say when no change is needed.

"One line per claim" makes the accuracy pass cover every claim, including ones the source cannot verify. "One each on clarity, tone, and repetition" gives the style pass a smaller, fixed scope without demanding invented faults. Each part gets a stated depth instead of sharing a vague "carefully".

## Exercise

Pick a recurring review task, such as checking a research summary against notes, a brochure against product information, or a lesson handout against the supplied reading. Use material you can provide. Write a single prompt for it.

Include both the material to review and the source to check it against in labelled source blocks after your completed prompt, including for the novice tier. Source blocks are task data, not extra instructions. Both the original and rewritten prompt must include the same blocks unchanged, so each fresh run has the same material.

The tutor checks that these blocks are present before dispatch. If material is missing, ask the learner to include it before running either prompt; do not silently add it or treat unsupported output as a verified result.

### Novice

Fill the blanks with a manner word, the one part of the task where depth matters most, and a measure for that part only — leave the manner word itself bare, with no measure attached across the whole task, so the depth of everything else is still left to guess — then send the completed line as your prompt.

> Review {{TASK}} ________, and for ________ specifically, ________.

### Working

Write a prompt for {{TASK}} where the depth of the work is set clearly enough that you could predict roughly how long the output would be before seeing it.

### Advanced

Write a prompt for {{TASK}} that sets two different depths for two different parts of the same task — one part gets more scrutiny than the other, and the prompt says which and by how much.
