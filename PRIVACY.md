# Privacy policy

Last updated: 18 August 2026

Prompting Wizard is published by Entuvo Labs. It is a set of files you install into an AI assistant you already use. Entuvo Labs does not operate a Prompting Wizard account system, website backend, or analytics service.

## What we collect

We do not collect personal information, lesson answers, prompts, scores, or `PROGRESS.md` contents.

Your course state stays in a local `PROGRESS.md` file on the machine or chat where you run the course. Entuvo Labs cannot read that file.

## What the course may fetch

A locally loaded copy may read the public `VERSION.md` file from this GitHub repository to see whether a newer version exists. Automatic checks happen at most once every seven days. An explicit "check for updates" request, or a missing or unreadable last-check date, can fetch again sooner. That request goes to GitHub, not to an Entuvo Labs server.

Marketplace-managed and skills-CLI installs still apply updates through those hosts. They may also make the same read-only `VERSION.md` fetch when a check is due.

GitHub, Claude, OpenAI, the skills CLI, and any other host you use may collect their own logs or install telemetry under their policies. Those are not Entuvo Labs services.

## Practice prompts

Lesson prompts run in your AI assistant, with that assistant's file and network access. Outputs stay in that session unless you save them.
