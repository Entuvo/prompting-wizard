# Lesson: Choosing an output

**The skill:** Name the specific thing you want when the model finishes. Pick that thing based on how you'll use it.

## Same request, three ways

**1. Topic only**
> Help me with packing for a weekend trip.

This names no output. You might get advice, a story, or questions back.

**2. A category, but the shape is open**
> Make a packing checklist for a weekend trip.

This is better. But you could still get 5 items or 40, grouped or ungrouped.

**3. A clear output, said briefly**
> Write a three-item checklist of essentials for a rainy weekend hike, one item per line, each starting with ☐.

Anyone reading only this prompt could picture the result:

```
☐ Rain jacket
☐ Water bottle
☐ Phone charger
```

## Why a checklist?

Choose the format by what you'll **do** with the output:

- **Tick things off** → checklist
- **Choose between options** → comparison table
- **Understand something** → short explanation

You'll use a packing list while packing, so a checklist fits better than a paragraph of advice.

## Quick test

Ask yourself: *Could two careful people give me different things from this prompt?* If yes, describe the output more clearly.

Don't over-correct, though. Only add words that make the output clearer. A short prompt that already names the output is a good prompt.
