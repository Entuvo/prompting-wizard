There is no email support queue and no account to recover. If PROGRESS.md is lost, the course asks whether to rebuild from a day number or re-run the assessment.

For local coaching, include host surface/version, Python version and content-free status output in a bug report. Do not attach your learner database, prompt excerpts or host transcripts. See compatibility and controls.

Learning Cards and plugins

See native plugins or the manual fallback. For plugin issues, include package version and install route; distinguish failure to install, load the skill, read its guide, or carry the card. Only Claude on the web has passed the device walkthrough; other web, desktop, iOS and Android surfaces have not been through it. Report the app/surface, date, missing step and a synthetic example; do not attach your personal card. Keep your latest complete card and a backup. With a missing card, the coach cannot reconstruct accepted history or safely claim mastery. A newly exported card does not replace an older project upload.

For pw history, include the source (claude-code, codex, chatgpt or claude), the SDK version where one is used, and the error field from the runtime's JSON output. Do not attach prompts, exports or ROOT/history files.
