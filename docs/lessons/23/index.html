Agent and tool prompting: tools, timing, and done

"Use the tools to sort out your task" says neither which tool serves which purpose nor when the work should stop.

Start the course

One change, same AI.

Your prompt
Use the tools to prepare a comparison of workshop venues from the supplied requirements and approved options. Do not contact anyone or make bookings.
A stronger version
Prepare a comparison of workshop venues from the supplied requirements and approved options. Use document search to locate the requirements, then spreadsheet tools to compare each option against every requirement. Use only the supplied material. Stop when every option has an answer for every requirement, with a document and page or section supporting each answer. Use "unknown" only after checking the supplied material; list the specific sections checked for that requirement and explain what information they lack, so the reader can verify each unknown against those sections. Return the comparison and any unresolved questions. If a required tool or source is unavailable, report that limit instead of claiming the comparison is complete. Do not contact anyone or make bookings.

Here is the test: could the assistant satisfy your definition of done by going through the motions? Replace that shortcut with evidence you can check.
