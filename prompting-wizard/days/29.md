# Day 29 — Capstone I: build it

## Concept

Every lesson so far isolated one thing: one lever, one technique, one property held still so you could see it clearly. A production prompt doesn't get that luxury — it has to hold all of it at once, for a task you'll actually run again, not a one-off example built to show off a single lever.

Pick the task you'd be most annoyed to keep hand-holding through a model — one you run often enough that a weak prompt costs you real time, repeatedly. Build the prompt you'd actually save: every lever and every technique from the last four weeks, applied to the extent this task needs, no further.

Applied means engaged, not maximised. A task with no branching logic doesn't need conjunction pushed to a 5; a task with one obvious deliverable doesn't need a schema. What can't be missing is anything the task actually depends on.

Here is the test: for every lever your prompt touches, could you defend a 4 or better against its rubric? Anything you can't defend, fix before you call it done.

## Before / After

**Before**

The tutor asks the learner which of their recurring tasks costs them the most when the prompt is weak — not the easiest task, the one where a bad prompt actually hurts. The learner names it in their own words, unprompted by any example from the tutor.

**After**

The learner writes the production prompt for that task: every lever deliberately set, and every technique from this week applied where the task needs it. The tutor scores it lever by lever and technique by technique against the rubrics covered so far, and the learner revises until every lever it engages clears a 4.

## Exercise

Ask the learner to name their highest-value recurring task per `## Before / After`, then record it, in the learner's own words, in the day-29 `## Log` line, so day 30 can read it back without asking again.

### Novice

Ask the learner to write a first pass at the production prompt for their named task, then go lever by lever, all eleven, stating what each currently sets.

### Working

Ask the learner to revise the prompt until every lever it engages scores 4 or above against its rubric, and every relevant technique from this week is applied.

### Advanced

Ask the learner to produce a prompt for their named task that scores 4 or above on every lever it engages, using no more words than the task requires. Have them defend, for each engaged lever, why 4 was enough or why it needed a 5.
