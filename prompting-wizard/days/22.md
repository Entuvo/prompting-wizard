# Day 22 — System prompts: separate what stays from what changes

## Concept

A prompt that repeats its rules every turn pays the same tax twice: once to write the rules, once to have the model re-read them alongside whatever's actually new. "Always cite your sources. Never use exclamation marks. Keep answers under 200 words. Now summarise {{TASK}}." Three of those four sentences would be true on any turn you sent this prompt again. Only the fourth changes.

The system prompt holds what doesn't change: standing behaviour still true on turn fifty. The per-turn ask holds only what's new this time. Move a durable rule into the per-turn slot and you retype it forever; leave a turn-specific detail in the system prompt and it silently governs requests it was never written for.

Leakage runs both ways: a durable rule restated every turn is redundant, and a turn-specific detail promoted into the system prompt is a landmine for the next request.

Here is the test: read your system prompt line by line and ask, would this be false on some future turn? If yes, it belongs in the per-turn ask.

## Before / After

**Before**

> Always cite your sources. Never use exclamation marks. Keep answers under 200 words. Summarise {{TASK}}.

**After**

System prompt:

> Always cite your sources. Never use exclamation marks. Keep answers under 200 words.

Per-turn ask:

> Summarise {{TASK}}.

Nothing was reworded. The three durable rules moved into a block that stays fixed no matter what gets asked next turn; the one thing that actually changes — the request itself — is all that's left in the per-turn ask.

## Exercise

Pick one of your recurring tasks. Write a single prompt for it.

### Novice

Take a prompt you've sent more than once for {{TASK}}. If it doesn't already carry two lines, each carrying a detail true only of this request — a date, a file name, this week's numbers — add them, kept separate from the request line. Then split it into two blocks: the request line goes in the per-turn ask, and every other line, those two included, goes in the system prompt. Send both blocks.

### Working

Split a prompt you've sent for {{TASK}} into a system block and a per-turn ask, putting every line on the side it belongs on except one: leave exactly one rule that would still be true on a future turn sitting in the per-turn ask.

### Advanced

Write a system prompt for {{TASK}} that stays unchanged across three different per-turn asks you could plausibly send tomorrow, and write all three asks. If any ask would force you to edit the system prompt, move that line down into the ask; if a line repeats in all three asks, move it up into the system prompt. Revise until neither move is left to make.
