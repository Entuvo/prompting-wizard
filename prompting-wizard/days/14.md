# Day 14 — Review: all eleven levers

## Concept

Eleven lessons back, you named an artifact. Since then you've set an operation, two qualities, a manner, a reference, a boundary, a condition, a quantity binding, a count, a marker, and a particle — eleven dimensions, each fixed by a different lever, blind to the other ten. A prompt can score full marks on nine and still fail, because the two left loose are the two the model needed. The noun tells it nothing about the fallback; the fallback tells it nothing about the count.

Today introduces nothing new — the same move as day 6, scaled up: run all eleven over one request and see which you reach for automatically, which you still forget. The forgotten ones cost you quality.

Independence cuts both ways. Not every lever needs pulling hard; some tasks have no fallback to state. What matters is every lever considered, and either set deliberately or left out on purpose.

Here is the test: score a prompt you'd call finished against each of the eleven rubrics in turn. A score of 2 or below is a dimension you thought you'd covered and hadn't.

## Before / After

**Before**

The tutor reads `## Levers` from the learner's `PROGRESS.md`, identifies the three lowest-scoring levers, and asks the learner for a real, hard prompt for one of their `## Tasks` entries — not a toy example, the prompt they'd actually be unsure about. That prompt, exactly as written, is the "before". Do not substitute an example; use the learner's own words.

**After**

The tutor does not supply a rewrite yet. The learner attempts their own revision first, deliberately setting all eleven levers, giving particular attention to the three named as weakest. Only after that attempt exists does the tutor produce a stronger version for comparison, scored against all eleven rubrics the same way as the learner's attempt.

## Exercise

Before presenting a tier, read `## Levers` from the learner's `PROGRESS.md`, identify the three lowest-scoring levers, and name them to the learner. Build the exercise below around exercising those three specifically, in addition to the rest.

### Novice

Ask the learner for a real prompt for one of their `## Tasks` entries. Have them go lever by lever, all eleven, in order, stating what each one currently sets — starting with the three named as weakest — then rewrite only those three into the prompt, leaving the other eight exactly as they are, and send that version.

### Working

Ask the learner to revise their prompt so every one of the eleven levers is deliberately set, with the three named as weakest addressed first and checked hardest.

### Advanced

Ask the learner to write a prompt for a real task that sets all eleven levers in under 60 words total, holding the three named as weakest to the same standard as the rest.

## Rubric

Score against `rubrics.md#noun`, `rubrics.md#verb`, `rubrics.md#adjective`, `rubrics.md#adverb`, `rubrics.md#pronoun`, `rubrics.md#preposition`, `rubrics.md#conjunction`, `rubrics.md#determiner`, `rubrics.md#numeral`, `rubrics.md#interjection`, and `rubrics.md#particle`.
