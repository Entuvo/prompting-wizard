# Day 5 — Preposition: scope and relation

## Concept

"Fix the problems in {{TASK}}" has an artifact, a verb, and one boundary — "in {{TASK}}". One boundary is not enough. Which problems, for whom, at what cost? Without an audience and an exclusion, the model can fix anything it deems a problem, however it likes, and hand you correct-but-unusable output.

Prepositions carry scope and relation: in what, for whom, without what. "In" bounds the territory. "For" names who has to be able to use the result. "Without" rules out side effects that would technically satisfy the request but break something you didn't mention because you assumed it was obvious.

All three matter, and they compound: scope narrows what's touched, audience shapes how it's explained, exclusion protects what must not change. Drop any one and the model fills the gap with its own default — usually the broadest reading of what's left unsaid.

Test it by asking three questions of your prompt: in what, for whom, without what. If any answer is missing, that's an open boundary the model will set for you.

## Before / After

**Before**

> Fix the problems in {{TASK}}.

**After**

> Fix the correctness problems in {{TASK}}, for a reader who has not seen the codebase, without introducing new dependencies.

"Correctness" narrows which problems. "For a reader who has not seen the codebase" sets the audience. "Without introducing new dependencies" rules out a fix that solves the problem by adding scope elsewhere.

## Exercise

Pick one of your recurring tasks. Write a single prompt for it.

### Novice

Fill the blanks with a scope and an audience — those two only, with nothing ruled out — then send the completed line as your prompt.

> Fix the ________ problems in {{TASK}}, for ________.

### Working

Write a prompt for {{TASK}} that sets a scope, names an audience, and rules out one side effect — all three, none left to the model's default.

### Advanced

Write a prompt for {{TASK}} that states an audience, a boundary, and an exclusion, each worded so it admits exactly one reading — a reader looking for a second way to satisfy any one of the three should not find one.
