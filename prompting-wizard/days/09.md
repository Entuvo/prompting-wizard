# Day 9 — Conjunction: conditional logic

## Concept

"Update {{TASK}} and handle the edge cases" hides a branch: which edge cases, and what happens for each? "And" bolts two directives together without saying how they relate, so the model has to invent both the branch and its outcome.

A conjunction like if / then / otherwise makes the branch explicit. "If the input is empty, return an empty result rather than erroring; otherwise process every row" states a condition, an outcome, and a fallback. Nothing is left to invent.

A conditional breaks two ways even when a branch is stated: the outcome can be missing — "handle empty input" names a condition, not what handling means — or the fallback can be missing, exactly as underspecified as no branching at all, since it's the branch everything else defaults to.

With more than one condition, order them the way you want them checked, so overlaps resolve as you intend, not however the model likes.

Here is the test: find every "and", "if", or "unless" in your prompt. For each, ask which of condition, outcome, and fallback is missing.

## Before / After

**Before**

> Update {{TASK}} and handle the edge cases.

**After**

> Update {{TASK}}. If the input is empty, return an empty result rather than erroring; otherwise process every row.

The seed's "and" hid a branch. "If / otherwise" names it: a condition, an outcome for that condition, and what happens to everything that doesn't match it.

## Exercise

Pick one of your recurring tasks. Write a single prompt for it.

### Novice

Fill the blanks with a condition, its outcome, and a fallback, then send the completed line as your prompt.

> Update {{TASK}}. If ________, ________; otherwise ________.

### Working

Write a prompt for {{TASK}} that states one condition, its outcome, and an explicit fallback for everything else — no edge case left for the model to invent.

### Advanced

Write a prompt for {{TASK}} that states two branches, each with its own condition, outcome, and fallback, ordered so a reader checks them in a fixed sequence with no overlap between them.
