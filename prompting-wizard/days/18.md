# Day 18 — Task decomposition: one output, one input

## Concept

A single prompt asking for three things at once forces the model to hold three goals while writing one. Ask for "a summary, then a list of risks, then a recommendation" in one pass, and the risks section quietly reshapes the summary, or the recommendation pre-empts risks it hasn't reached yet. The tasks aren't independent — they share one context and interfere.

Splitting into three prompts only fixes this if each step's input is exactly the last step's output: nothing added, nothing re-explained. Restate the task at step two and you haven't decomposed anything — you've just moved the interference into your own head.

Find the "and then" in your own prompt. That's the seam. Cut there, and check that what crosses it is an output, not a summary of one.

Here is the test: cut a chained prompt of yours at every "and then," and check whether each half's input is verbatim the other half's output — not a paraphrase, the actual text.

## Before / After

**Before**

> Summarise {{TASK}}, then list every risk in that summary, then recommend whether to proceed.

**After**

Prompt 1:

> Summarise {{TASK}} in no more than 150 words.

Prompt 2 — input is Prompt 1's output, pasted verbatim:

> Here is a summary: "[Prompt 1's output, unedited]". List every risk it implies, one per line, citing the sentence that raises it.

Prompt 3 — input is Prompt 2's output, pasted verbatim:

> Here is a risk list: "[Prompt 2's output, unedited]". Recommend proceed or don't, in one sentence, naming exactly one risk from the list as the deciding factor.

Three passes, each with one job. Nothing in prompt 2 re-explains {{TASK}}; it only sees the summary. Nothing in prompt 3 re-reads the summary; it only sees the risks. Each seam carries exactly the last step's output.

## Exercise

Pick one of your recurring tasks. Write a single prompt for it.

### Novice

Write a single chained prompt for {{TASK}} with three asks in it, then split it into three prompts where each one's input is the previous prompt's output summarised in your own words rather than pasted — a paraphrase at every seam, not the actual text — and send the three prompts.

### Working

Write three prompts for {{TASK}} where each step's input is the previous step's output plus exactly one line of added instruction. Nothing from the original task may be re-explained.

### Advanced

Write a one-line brief for {{TASK}} that the whole chain must satisfy, then split it into three or more prompts so every seam carries exactly the previous step's output, verbatim, nothing added and nothing re-explained — check each seam by pasting the real output across it. Then add one adversarial constraint to the brief that a lazy decomposition would fail — for example, requiring the last step to cite a detail that only survives if the middle step passed its output through unparaphrased — and confirm your chain satisfies it.
